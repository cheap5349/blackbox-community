黑盒社区 · 背景音乐目录
========================

这里放你自己的音乐文件。仓库刻意不含任何音频，避免版权问题。

两种用法，任选其一：

1) 单曲（最省事）
   把一首 mp3 命名为 bgm.mp3 放在本目录：
     public/audio/bgm.mp3

2) 播放列表
   复制 playlist.example.json 为 playlist.json，再改成你的曲目：
     public/audio/playlist.json
   格式：
     { "tracks": [ { "title": "曲名", "src": "/audio/xxx.mp3" } ] }

说明
----
- src 用站点绝对路径（/audio/...）；文件放在本目录即可通过 /audio/ 访问。
- 格式支持浏览器能解码的：mp3 / m4a / ogg / wav（具体取决于浏览器）。
- 播放器默认不自动播放。只有你上次点过播放，才会记住偏好并在下次进站时续播；
  浏览器会拦截"没有用户交互"的自动播放，这时点一下播放键即可。
- 左下角圆钮是播放器入口，点击向右滑出面板（音量、上一首 / 下一首、曲目序号）。
