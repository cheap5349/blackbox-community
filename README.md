# 黑盒社区

基于 Vue 3 + Vite + Node.js + Express + MySQL 的社区项目，含暗色主题切换、粉调浅色 / 星空暗色背景（含流星）、白场终端风格开场动画、矢量图标体系、实时性能徽标、背景音乐播放器、动效交互与匿名讨论区（树洞）。

开场动画参考 [RhineLabUI](https://github.com/LBEILC/RhineLabUI) 的运动技法自行实现（单调三次插值轨道 / 25fps 整数帧打字 / 硬切换幕 / 单帧毛刺），文案与图形为黑盒社区自有，未使用其素材。时间轴是纯函数（`src/intro.js`），渲染层逐帧直写 DOM 不走 Vue 响应式，有 20 条单测覆盖。

首访完整播放，之后可在页头手动重播（偏好存浏览器本地）；`prefers-reduced-motion` 命中时立即跳过；首屏等待真实数据就绪，加载失败或超过 4 秒仍放行，不会卡在开场层。

## 启动

1. 安装 Node.js 18+ 与 MySQL 8+
2. 执行 `server/schema.sql` 初始化数据库（`reports` 等新表也会由服务启动时的自动迁移创建）
3. 复制 `.env.example` 为 `.env`，填写数据库配置，**务必设置 `JWT_SECRET`**
4. 执行 `npm ci`（首次或依赖变更时）
5. 执行 `npm run dev`

前端地址：`http://localhost:5173`，API 地址：`http://localhost:3000`。

## 功能

- **认证**：注册 / 登录（JWT，7 天有效）、个人中心（昵称、头像、简介、修改密码）；登录与注册有速率限制
- **社区**：浏览全部社区、创建社区、进入社区查看帖子、社区详情统计
- **帖子**：发布（图片/视频上传）、点赞、评论、删除；**编辑自己的帖子**（个人中心或帖子详情页）
- **排序与运营**：发现页支持 **最新 / 热门 / 精华** 三种排序；管理员可**置顶**、**加精**帖子（置顶在所有排序中恒在最前）
- **站内通知**：被点赞 / 被评论 / 举报受理 / 账号治理结果会推送到通知中心，页头铃铛显示未读角标（60 秒低频轮询，页面隐藏时暂停）。不给自己发通知；**讨论区（树洞）的互动不产生通知**，避免破坏匿名性
- **搜索**：Ctrl/Cmd + K 全局搜索（标题/内容/作者/社区）
- **匿名讨论区**：发帖、评论均匿名展示
- **举报治理**：帖子详情页可举报违规内容，管理员在后台「举报」页签中忽略或删除并结案
- **用户治理**：管理员可**封禁 / 解封**、**禁言 / 解禁**（1 小时 ~ 7 天可选）、**授予 / 撤销管理员**；被治理的用户会收到系统通知
- **内容安全**：发帖 / 评论 / 编辑均经过敏感词过滤——违法违禁类直接拒绝（返回命中的词），广告导流类等长打码后放行
- **管理后台**：帖子 / 社区 / 用户 / 举报 管理，支持搜索、编辑、删除与数据统计
- **隐私克制**：天气在进入页面时按 IP 解析到城市级并展示，**不展示也不保存 IP 地址**；除此之外不做任何默认采集

## 界面元素

- **矢量图标**：界面图标全部来自 `src/icons.js` 的 24×24 描边路径，经 `src/components/AppIcon.vue` 渲染（`<AppIcon name="search" :size="16" />`）。此前用 `⌁ ◌ ▢ ↻ ⌕ 🔔 ✦ ＋` 等文本字符充当图标，这些字符在部分字体下缺字形、会被渲染成空心方框，看起来像页面缺了内容，现已全部替换
- **实时性能徽标**：页头右上角常驻，显示当前帧率与 `/api/health` 的往返延迟，点击展开详情。延迟按 < 120 ms / < 350 ms / 更高分三级，用指示灯颜色区分；页面隐藏时暂停采样
- **背景音乐播放器**：左下角常驻一台小黑胶唱片机（播放时唱片匀速转动、唱臂落到盘面，暂停时抬起），点击唱片才向右滑出面板：面板里有当前曲目（缩略黑胶封面 + 曲名 + 序号）、可拖动的播放进度条与两侧时间、上一首 / 播放暂停 / 下一首、音量。把音频放进 `public/audio/` 即可：
  - 最简用法：放一个 `public/audio/bgm.mp3`
  - 多曲目：复制 `public/audio/playlist.example.json` 为 `playlist.json`，按其中的格式填写

  播放行为：页面加载完曲目即**自动播放**（用户上次手动暂停过则跳过）；若浏览器以"没有用户手势"为由拒绝，播放器会安静等待，用户第一次点击 / 按键 / 触摸页面时立刻续播。单曲由 `audio.loop` 无缝循环（不会中途断掉重来），多曲才在播完后切下一首。单曲循环的最后 1.8 秒会柔和淡出、回到开头再淡入（`src/bgm.js` 的 `loopGain` + `useBgm.js` 的 rAF 跟随），这样接缝处不会突然"从头发声"。开关偏好记在 `localStorage['heibox.bgm.v1']`（`off` = 用户主动关过），音量记在 `heibox.bgm.volume`

  > 注意：仓库里自带的示例 `public/audio/bgm.mp3` 只有 **27 秒**，所以每隔 27 秒就会循环一次。想听完整歌曲请替换成完整音频文件，或放多首并配置 `playlist.json`。
- **主题背景**：浅色主题是**粉色落英**——底色取自 `:root` 的 `--blush-1..4` 四档粉色变量（已加深到一眼就能看出是粉），叠加四团粉光、三条粉色极光带与一层很淡的洗层；46 片大小不一的花瓣边侧摆边旋转飘落（`petalStyle()` 给每片不同的尺寸、摆幅、翻转圈数与速度）。暗色主题是**漫天星河**——四层 `box-shadow` 星尘（远 / 中 / 银河带 / 近景，一层几百颗星只占一个 DOM 节点）+ 银河斜带 + 3 团星云 + 64 颗按远近分层闪烁的亮星 + 16 颗流星；每颗流星的倾角、长度、速度、延迟都独立（`meteorStyle()` 算出 `--angle / --fx / --fy`，由同一套 `meteorFall` 关键帧消费），所以是各飞各的而不是排队划过。两者都只动 `opacity` / `transform`，且 `prefers-reduced-motion` 或页面滚动时会暂停装饰动画

## 安全说明

- `JWT_SECRET` 缺失或仍为默认值时，**生产环境（NODE_ENV=production）会拒绝启动**，防止 token 被伪造
- CORS 默认仅放行本地开发端口，生产环境请通过 `CORS_ORIGINS` 配置域名白名单
- 上传文件不信任客户端 mimetype，按文件头二次校验；头像以文件形式存储，不再写 base64 进数据库
- 已开启安全响应头与请求限流；文件存储走 S3 协议抽象（MinIO / 阿里云 OSS / 腾讯云 COS），未配置 `S3_*` 环境变量时回退本地磁盘
- **账号状态以数据库为准**：JWT 是无状态的，签发后无法撤销，因此需要鉴权的接口会回查一次 `users` 表。封禁与撤销管理员**对已签发的旧 token 立即生效**，不必等 7 天过期
- 管理员的封禁 / 降权操作有自锁保护：不能对自己执行，避免把管理后台锁死
- 列表排序参数走白名单映射，不把请求参数拼进 SQL 的 `ORDER BY`

## 部署

- **Docker Compose**（推荐）：`docker compose up -d --build` 一键拉起 MySQL 8 + MinIO + API（含前端静态托管），三个服务带健康检查
- **PM2 + Nginx**：`ecosystem.config.cjs` 提供进程守护配置，反向代理示例见 [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)

上线前请核对 [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) 的必做清单：替换默认 `JWT_SECRET` 与数据库密码、配置真实域名 CORS、确认 `S3_PUBLIC_URL` 浏览器可达。

## 测试

- `npm test`：后端 `node:test + supertest` 59 条（auth / 帖子 / 点赞 / 评论 / 举报 / 权限 / 存储 / **通知** / **用户治理** / **敏感词**）与前端 `vitest` 186 条（15 个文件：工具函数 / store 流转 / 组件渲染 / **开场动画时间轴** / **图标与性能工具** / **背景音乐清单与播放状态机** / **性能徽标与播放器组件** / **样式守卫** / **模板编译守卫**）全量执行
- `npm run lint` 与 `npm run format:check`：ESLint 9 flat config + Prettier 门禁；约定见 [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md)

> 测试会连续注册大量账号，必然超过面向真实用户的登录 / 注册限流阈值。测试辅助在导入应用前设置 `RATE_LIMIT_DISABLED=1` 关闭限流；生产环境不设置该变量，限流行为完全不变。
